01

從不可見，到可見

微中子本身不直接發出這裡的切倫科夫光。罕見的作用產生帶電次級粒子，這些粒子在冰中形成光訊號，讓 DOM 記錄時間與模型電荷。

02

真值不是重建

黃色實線是模型已知的次級粒子路徑。青色虛線與箭頭是根據命中計算的候選 LineFit。Starting 拓撲或不利的感測器分布可能讓它嚴重偏離，甚至反向。

模擬真值來向只存在於模擬中；SIMULATION QA ONLY 不能視為真實事件的可信度。

03

教學模型的邊界

這不是官方 IceCube 模擬，也不是 PPC / CLSim 或定量校準的偵測器與重建。冰層傳輸、光量及散射延遲未以官方偵測器資料校準。

Cascade 的模型光分布完全等向，不能識別物理入射方向。亮度、點大小與光暈是視覺映射，不代表校準能量。
